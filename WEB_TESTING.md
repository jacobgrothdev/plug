# The Plug — Web Testing

This project is configured to build automatically for the web with GitHub Actions and publish through GitHub Pages.

After the repository is pushed to `main`, open **Actions** and wait for **Build and Deploy The Plug Web** to finish.

Then the game will be available at:
`https://YOUR-GITHUB-USERNAME.github.io/plug/`

The first web prototype uses Godot's Compatibility renderer and a single-threaded web export for broad browser compatibility.
