# THE PLUG — Prototype 0.1

A vertical, stylized 3D mobile game prototype built in Godot 4.x.

## Current playable loop

- Start with **$150**, **0.5 oz**, and **3 seeds**.
- Walk around a small neighborhood.
- Visit the **Garden Center**.
- Buy pots, soil, fertilizer, watering can, and a basic grow light.
- Visit the shed and plant seeds.
- Plants grow while the game is open **and while you're away** using a timestamp-based idle system.
- Harvest ready plants into inventory.
- Open the in-game phone for business, inventory, and map placeholders.

## Visual direction

Chunky, low-poly 3D inspired by the broad readability of mobile games and the personality of GTA Chinatown Wars, with a vertical phone-first UI.

## Controls

- Desktop prototype: WASD to move.
- Mobile controls: the UI and interactions are touch-friendly; a dedicated virtual joystick is planned for the next prototype pass.
